# 当前完成度与未完成项

## 本轮已处理

- 手机状态屏改为两页结构：
  - 浅色基础页。
  - 点击像素小人进入黑色常驻展示页。
- 常驻展示页改为纯黑背景，无光效。
- 常驻展示页支持：
  - 左侧放大像素小人。
  - 右侧实时状态和调用日志。
  - 进入全屏 / 退出全屏。
  - 返回基础页。
  - Wake Lock 尝试保持屏幕常亮。
- Claude Code hooks 已接入。
- Codex hooks 已安装，但需要在 Codex 里运行 `/hooks` 并信任。
- 语音播报已改为按事件队列播报，不再只播完成状态。

## 仍未完成但必须做的工程项

### 1. VS Code / Cursor 扩展

当前还没有真正接入 VS Code 和 Cursor 的编辑器状态。

需要做：

- 文件保存/修改。
- 终端命令开始/结束。
- Task 开始/结束。
- diagnostics 错误数量。
- 工作区打开/关闭。

用途：

- 判断编辑器层面是否在运行测试、构建、保存、报错。
- 和 Claude Code / Codex 的 Agent 生命周期互补。

### 2. 桌面悬浮像素小人

网页无法真正做系统级透明置顶悬浮窗。

需要 Tauri 或 Electron：

- 透明窗口。
- 置顶。
- 鼠标穿透可选。
- 拖拽位置。
- 只显示像素小人，不显示日志。

### 3. 原生手机 APP

当前是 Web 原型。

原生 APP 需要：

- 局域网设备发现。
- 扫码配对。
- 后台/前台语音播报控制。
- 常亮控制更稳定。
- 横屏常驻展示。

建议用 Expo / React Native 先做。

### 4. 唤醒词

浏览器无法稳定常驻监听 `Hello Code`。

需要：

- 桌面端：openWakeWord / Porcupine / Windows Speech。
- 手机端：原生语音识别或按住说话。

第一版建议：

- 先做按键语音查询。
- 再做桌面端唤醒词。

### 5. 国产 Code 软件即开即用

需要做适配器分层：

1. VS Code 兼容类：安装统一 VS Code 扩展。
2. 有插件 API 的国产 IDE：写专用 adapter。
3. 无插件 API：通用弱监控。

通用弱监控包括：

- 进程名。
- 窗口标题。
- 工作区文件变化。
- 系统通知。
- OCR / 无障碍树。

### 6. 安全与配对

当前局域网 API 还没有配对 token。

正式版本必须做：

- 手机扫码配对。
- token 鉴权。
- 一键撤销设备。
- 路径脱敏。
- 默认只监听本机，用户打开局域网模式后才对外暴露。

## 模拟状态的定位

真实监听正常后，模拟状态不应该出现在用户主界面。

它仍然有用，但只应保留在：

- 开发者调试页。
- 皮肤测试。
- 语音播报测试。
- 演示模式。
